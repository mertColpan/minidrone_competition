# Minidrone Competition Project

This repository contains our project developed for the **MathWorks Minidrone Competition 2025**, for which we have qualified for the **Turkey national finals**.

## 📦 Clone the Repository

To clone this repository, run the following command in your terminal:

```bash
git clone https://github.com/mertColpan/minidrone_competition.git

```
## Run

    Open the .Mergen.mlproj file with MATLAB.

    Make sure Simulink and all the necessary packages are installed.

    Before starting the simulation, ensure to define a new flight path as needed.
